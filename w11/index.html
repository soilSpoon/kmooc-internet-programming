📅 7일간의 날씨 예보 (Open-Meteo Forecast API)

📌 K-MOOC 인터넷프로그래밍 과제 기술 구현 명세

  • Open API #1: Open-Meteo Weather Forecast API — 실시간 기상 관측 데이터(온도, 체감온도, 습도, 풍속, 강수량) 및 7일 일별 예보 REST API 호출
  • Open API #2: Open-Meteo Geocoding API — 전 세계 도시명 실시간 지오코딩(위도·경도 좌표 변환) 검색
  • Open API #3: Wikipedia REST API — 선택된 도시의 백과사전 요약문 및 대표 썸네일 이미지를 비동기 로드
  • 핵심 기술: JavaScript 비동기 Fetch API (AJAX), Promise & async/await, 브라우저 새로고침 없는 동적 DOM 렌더링(SPA)
  • 배포 환경: AWS EC2 / Vercel 기반 웹 서버 배포 (https://kmooc.mlz37.work/w11/)
